# TermCMD (Agent Terminal Multiplexer & Desktop Canvas)

A high-performance desktop terminal canvas and orchestration manager designed for AI agent workflows and human-in-the-loop terminal monitoring.

## Highlights
- **Persistent PTY Sessions**: Real-time pseudo-terminal lifecycle management.
- **Embedded Agent API**: REST, Server-Sent Events (SSE), and WebSocket interfaces for external agents and CLI tools.
- **Kitty Aesthetic & Smooth Cursor Trail**: WebGL-accelerated rendering with spring physics cursor trailing.
- **Desktop Canvas Window Manager**: Floating, draggable, resizable terminal boxes with minimize dock and live status pills.
- **OSC 133 Shell Integration**: Clean semantic command boundary and exit code detection.
